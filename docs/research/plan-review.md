# Implementation plan review

Reviewed September 19, 2026 against the product brief and runtime, storage, interaction, onboarding, insertion, and validation research. Read-only review of proposed behavior; no app runtime claims were tested. Findings below need plan amendments, not more features.

1. **P1: Put retention enforcement in the first personal-use build.** [Milestone 2](../implementation-plan.md#implementation-order-and-gates) creates durable history, but milestone 3 introduces retention. Meanwhile [storage defaults](../implementation-plan.md#modules-and-data-ownership) promise seven-day audio expiry during setup. A user can run milestone 2 longer than seven days. Move audio expiry, explicit deletion, and interrupted-deletion recovery into milestone 2. Defer only the advanced retention editor. Its gate should advance a controlled clock, restart, and verify expired audio disappears while retained text remains. The [storage research](storage-and-model-management.md#durable-history-and-deletion) already supplies the needed contract.

2. **P1: Define history retry separately from live dictation.** The [lifecycle](../implementation-plan.md#one-recording-lifecycle) permits a history retry job but only specifies live-recording mode resolution and insertion. It does not say whether retry uses the historical snapshot or current mode, whether a missing local model may lead to selecting a cloud model, or whether retry can auto-paste. Add an explicit retry intent: display its chosen models and processing location, require an explicit action before sending retained audio/text remotely, recheck current local policy, and hold the result for Copy by default. Preserve the original result until retry succeeds. Test an old local entry after its mode changes to cloud and after its speech model is removed. This implements the brief's [history requirement](../product-brief.md#history) against automatic uploads of old content.

3. **P2: Specify the mandatory Cohere failure outcome.** [Milestone 1](../implementation-plan.md#implementation-order-and-gates) says failed gates choose an alternative, but the fallback paragraph only retains a separately validated MLX path for Cohere. If that path fails memory, correctness, or offline tests on the proposed minimum Mac, there is no documented replacement. State that local Cohere remains a blocking compatibility issue, and identify the decision needed: another conversion/runtime, a revised hardware floor, or an explicit product-scope revision. A helper process addresses isolation/cancellation, not an unsupported checkpoint or excessive total memory. Do not let success with another speech model clear the requested-feature gate.

4. **P2: Define which session types contribute to dictation statistics.** The [metrics rule](../implementation-plan.md#modules-and-data-ownership) names completed transcriptions, cumulative recording time, and raw dictated words. The plan later adds system-audio meetings, but never defines whether their participants, silence, or imported/retried audio count toward the user's WPM. Store session origin and define one eligibility rule for both words and duration before introducing durable aggregates. A sensible initial rule is successful microphone dictation only, counted once, with meetings excluded from dictation WPM. Test a mixed history fixture. Otherwise aggregates become difficult to repair after underlying history expires.

The temporary-copy project build is accurately bounded evidence. It supports fixing project format/deployment compatibility first; it establishes nothing about signed distribution, native dependencies, or actual model readiness. No additional build blocker was found in this review.

## Disposition

Verified the amended plan on September 19, 2026. All four findings are resolved at the planning level. Milestone 2 now enforces retention and deletion. History retry preserves original results, requires explicit model/provider choices, checks current policy, and disables automatic insertion. Local Cohere failure explicitly blocks milestone 3 and the complete requested release. Home metrics count dictation sessions and exclude meetings. Original findings remain above as the review record; implementation and runtime validation are still pending.
