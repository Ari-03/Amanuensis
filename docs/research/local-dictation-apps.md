Handy and VoiceInk references for Amanuensis

Researched September 19, 2026, using official documentation and repositories. This is a product and implementation reference, not a hands-on accuracy benchmark. Recommendations below are our design judgments.

VoiceInk is the closer reference for the requested macOS interface and modes. Handy is useful for unrestricted local model discovery and the less visible details that determine whether dictation feels reliable.

| Area | Handy | VoiceInk |
| --- | --- | --- |
| Local models | Discovers user-provided Whisper GGML `.bin` models in its models folder. It also reuses supported models in the shared Hugging Face cache. Manual installation is documented. [README](https://github.com/cjpais/Handy#custom-whisper-models) | Has an explicit Import Local Model action for whisper.cpp-compatible `.bin` files. Imported models become selectable inside Modes. Parakeet and Whisper downloads have delete controls, and Parakeet files can be revealed in Finder. [Local models](https://tryvoiceink.com/docs/local-models) |
| Cleanup models | Provides a separate post-processing hotkey, selectable provider/model, and editable prompt templates. These are visible in the current settings strings. [Settings source](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/src/i18n/locales/en/translation.json#L402) | Separates the model catalog from Modes. A Mode selects transcription and optional enhancement independently. Local enhancement includes Ollama; a Local CLI adapter can invoke commands. A CLI adapter does not itself guarantee offline inference. [Catalog](https://tryvoiceink.com/docs/ai-models), [Local models](https://tryvoiceink.com/docs/local-models) |
| Modes | The reviewed settings expose transcription, post-processing prompts, and a dedicated cleanup hotkey. App-based mode routing was not established by this review. [Settings source](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/src/i18n/locales/en/translation.json#L160) | Modes combine model, prompt, context, output, triggers, and shortcut. Starter modes include Dictation, Enhancement, Email, Rewrite, and Assistant. Enhancement can be disabled. [Modes](https://tryvoiceink.com/docs/modes) |
| Automatic activation | Not verified in the reviewed sources. | Checks the active app when recording starts. A matching website can override the browser's app match; a dedicated mode shortcut bypasses automatic matching. Duplicate app and website assignments are rejected. [Mode triggers](https://tryvoiceink.com/docs/mode-triggers) |
| Vocabulary | A custom-word list has add/remove controls and rejects duplicates. The UI describes model guidance and fuzzy correction. This review did not establish a separate exact-replacement editor. [Custom words source](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/src/components/settings/CustomWords.tsx), [Settings source](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/src/i18n/locales/en/translation.json#L377) | Explicitly separates recognition vocabulary from deterministic replacements. Replacement matching ignores case, respects word boundaries for spaced languages, and considers longer phrases first. Multiple mishearings can map to one result. [Vocabulary](https://tryvoiceink.com/docs/vocabulary), [Replacements](https://tryvoiceink.com/docs/word-replacements) |
| Shortcuts | Supports hold, toggle, and combined hold-or-toggle activation. [README](https://github.com/cjpais/Handy#how-it-works) | Supports independent primary and secondary recording shortcuts, toggle/push-to-talk/hybrid behaviors, per-mode shortcuts, cancel, retry, paste last transcript, and quick dictionary entry. Hybrid treats a hold of at least 0.5 seconds as push-to-talk. [Shortcuts](https://tryvoiceink.com/docs/shortcuts) |
| Insertion | Offers clipboard paste, simulated typing, and no-paste behavior. Clipboard preservation is separately configurable. [Settings source](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/src/i18n/locales/en/translation.json#L320) | Mode output can paste, show a response in the recorder, or run a custom command. Optional auto-send follows insertion with a configured Enter combination. [Mode settings](https://tryvoiceink.com/docs/mode-settings) |
| Recording UI | Minimal/live overlays have waveform feedback and separate transcription/processing states. The source keeps an arming state until actual microphone samples arrive. [Overlay source](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/src/overlay/RecordingOverlay.tsx) | Documents a top-of-screen Notch style and floating Mini style. Both can show partial text with a streaming-capable model. [General settings](https://tryvoiceink.com/docs/settings-general) |
| Distribution and license | Marketed as free; repository uses MIT. [Website](https://handy.computer/), [License](https://github.com/cjpais/Handy/blob/8f9cf53cd1410cda26beea39ff802ac306e39585/LICENSE) | Native macOS app with source builds available and a paid compiled distribution. The README identifies GPLv3 and describes paid benefits including automatic updates and support. [Repository](https://github.com/Beingpax/VoiceInk#license) |

Handy's insertion troubleshooting deserves attention. It documents a failure where restoring the old clipboard on a fixed timer lets a busy receiving app paste the previous clipboard contents. Its experimental Reliable Paste waits for clipboard read notifications. That is evidence that correct transcription alone is insufficient; insertion must be tested with real destination apps under load. [Handy troubleshooting](https://github.com/cjpais/Handy#previous-clipboard-content-is-pasted-instead-of-the-transcription)

Recommended decisions for Amanuensis:

- Put Import model beside Download model. Show file format, location, size, supported capabilities, and readiness. Offer Reveal in Finder and Rescan. Importing must not require an account or a paid entitlement. Start with explicitly supported formats; unrestricted use does not imply compatibility with every model format.
- Keep one model library and let each mode select a speech model and optional cleanup model. Include an explicit cleanup Off setting. Display whether each selected stage runs locally, since local speech recognition followed by hosted cleanup still sends transcript text off the Mac.
- Borrow VoiceInk's clear split between vocabulary hints and exact replacements. For English replacements, specify whole-word matching, longest phrase first, and whether replacement output is processed again. Avoid chained substitutions by default.
- Use explicit mode shortcut, then website match, then app match, then default as the proposed routing order. Show the selected mode in the recorder before capture. Freeze it for that recording so switching windows cannot silently change the writing style halfway through.
- Keep toggle recording editable on Home and in Configuration through the same setting. Add push-to-talk and cancel there too. Retry and paste-last are useful follow-ups because they recover failed delivery without asking the user to repeat themselves.
- Give the recorder separate Preparing, Recording, Transcribing, Cleaning up, Done, and Failed states. Animate input levels only when samples arrive. Provide both notch placement and a floating fallback for external monitors or user preference.
- Treat reliable insertion and clipboard restoration as first-release work. Preserve the raw transcript and offer Copy when automatic insertion fails. Auto-send should require an explicit user setting per mode.

The reviewed sources establish that these interactions exist, but do not prove latency, accuracy, import compatibility with an arbitrary downloaded file, or reliable behavior in every app. The comparison also does not establish speaker identification or system-audio meeting capture in either product. Keep those as separate feasibility questions. Application source licensing and individual model licenses are separate; inspect the actual licenses before reusing code or distributing weights.
